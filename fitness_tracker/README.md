# מחלץ נתוני ריצה מצילום מסך ← טבלה (Fitness Tracker)

מקבל צילום/י מסך של ריצה מ-Apple Fitness, מחלץ את הנתונים באמצעות מודל ראייה של
Claude, ומוסיף אותם כשורה חדשה מתחת לשורות הקודמות בטבלה — בפורמט המדויק של
הקובץ שלך.

הכול נבנה סביב קובץ הדוגמה ששלחת: `template/fitness_master.xlsx` (גיליון
`ריצות`, 10 עמודות, וגיליון `תזונה` נשמר כמו שהוא עם הנוסחאות).

---

## מה מחולץ מכל ריצה

| # | עמודה (כותרת בקובץ) | מאיפה בצילום | פורמט | דוגמה |
|---|---|---|---|---|
| A | Date | כותרת "Tue, 4 Aug" | `D.M.YY` | `4.8.26` |
| B | Time | "5:17–6:17" | `HH:MM-HH:MM` | `05:17-06:17` |
| C | Duration[HH:MM:SS] | "Workout Time 1:00:04" | `H:MM:SS` | `1:00:04` |
| D | Distance[Km] | "8.65KM" | מספר | `8.65` |
| E | Avg. Heart Rate | "160 BPM" | שלם | `160` |
| F | Avg. Pace | "6'56''/KM" | `mm:ss` | `6:56` |
| G | Elevation Gain[m] | ⚠️ מסך נפרד | שלם / `X` | `52` |
| H | Avg. Power[W] | "151W" | שלם | `151` |
| I | Avg. Cadence[SPM] | "161SPM" | שלם | `161` |
| J | Temeture[C] | "TEMP 25°" | שלם | `25` |

**חשוב:**
- **צריך שני צילומי מסך לכל ריצה** — ה-Summary (זמן/מרחק/הספק/קצב/דופק/צעדים)
  וה-Map (טמפרטורה). המערכת קוראת את שניהם יחד.
- **Elevation Gain (טיפוס)** לא מופיע ב-Summary ולא ב-Map. אם לא צירפת מסך שמראה
  אותו — הערך נכנס כ-`X`, בדיוק כמו שכבר יש אצלך בהרבה שורות.
- **השנה** לא מופיעה בצילום של Apple. ברירת המחדל היא השנה הנוכחית (אפשר לשנות).

## איך זה בנוי (שתי שכבות)

```
                 (רץ על האייפון)                (מנוע פייתון — נבדק ועובד)
  צילום מסך ──►  Shortcut  ──►  Claude Vision  ──►  שורת CSV  ──►  Runs.csv (iCloud)
                                                                      │
                                                         csv_to_xlsx.py │ (מתי שרוצים)
                                                                      ▼
                                                    fitness_master.xlsx (התבנית המלאה)
```

1. **על האייפון** — קיצור (Shortcut) ששולח את התמונה ל-Claude ומקבל שורה מוכנה,
   ומוסיף אותה ל-`Runs.csv` ב-iCloud Drive (נפתח ב-Numbers/Excel כטבלה).
   מדריך התקנה מלא: [`shortcut/SHORTCUT_SETUP_he.md`](shortcut/SHORTCUT_SETUP_he.md).
2. **המנוע (פייתון)** — הלוגיקה שמנרמלת ומשבצת שורות בקובץ ה-xlsx תוך שמירה על
   העיצוב וגיליון התזונה. אפשר להריץ אותו ישירות על צילומי מסך, או להמיר איתו את
   `Runs.csv` לקובץ ה-xlsx המלא.

> למה שתי שכבות? האייפון לא יכול להריץ פייתון, אז הקיצור כותב ל-CSV פשוט (שגם הוא
> טבלה תקינה), והמנוע בפייתון משחזר את קובץ ה-xlsx המעוצב עם גיליון התזונה מתי
> שרוצים. אם תעדיף שהנתונים יזרמו **ישירות** לגיליון בענן בלי שלב המרה — אפשר
> להוסיף גרסת שרת קטנה (Google Apps Script). תגיד ואבנה.

## הרצת המנוע ישירות (מחשב)

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...

cd engine

# צילום/ים ← שורה חדשה בקובץ:
python cli.py --master ../template/fitness_master.xlsx  summary.png  map.png

# רק לראות מה יחולץ, בלי לכתוב:
python cli.py --dry-run --master ../template/fitness_master.xlsx  summary.png  map.png

# להמיר את יומן ה-CSV מהאייפון לקובץ ה-xlsx המלא:
python csv_to_xlsx.py --csv Runs.csv --master ../template/fitness_master.xlsx --out updated.xlsx
```

- המערכת **לא מוסיפה כפילויות**: אם כבר קיימת שורה עם אותם תאריך + שעה, היא
  מדלגת.
- כל שורה חדשה יורשת את העיצוב של השורה שמעליה, כך שהטבלה נשארת אחידה.

## מבנה הפרויקט

```
fitness_tracker/
├── README.md                     ← המסמך הזה
├── requirements.txt
├── engine/
│   ├── schema.py                 ← הגדרת העמודות + נירמול הערכים
│   ├── extract.py                ← קריאה למודל הראייה (JSON)
│   ├── append_row.py             ← הוספת שורה ל-xlsx בשמירת עיצוב/נוסחאות
│   ├── csv_to_xlsx.py            ← מיזוג יומן ה-CSV מהאייפון לתבנית
│   ├── cli.py                    ← הרצה מקצה לקצה
│   ├── prompt.txt                ← פרומפט חילוץ (פלט JSON)
│   └── prompt_line.txt           ← פרומפט חילוץ (פלט שורת CSV, לשורט-קאט)
├── shortcut/
│   └── SHORTCUT_SETUP_he.md      ← מדריך בניית הקיצור באייפון
├── template/
│   └── fitness_master.xlsx       ← קובץ היעד (התבנית שלך)
├── samples/                      ← שני צילומי המסך לדוגמה
└── tests/
    └── test_engine.py            ← בדיקות (נירמול + הוספה + כפילות)
```

## בדיקות

```bash
cd tests && python test_engine.py
```

התזונה והנוסחאות נשמרים.
