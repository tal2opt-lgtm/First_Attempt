# בניית ה"אפליקציה" על האייפון — קיצור (Shortcut)

המטרה: לצלם מסך של ריצה ב-Apple Fitness, ללחוץ **Share → "הוסף ריצה לטבלה"**,
והנתונים נשמרים כשורה חדשה בקובץ `Runs.csv` ב-iCloud Drive. את הקובץ הזה פותחים
ב-Numbers או ב-Excel והוא הטבלה שגדלה עם הזמן.

> הקיצור מדבר ישירות עם מודל הראייה של Claude — אין שרת, הכול רץ על הטלפון.

---

## מה צריך פעם אחת לפני שמתחילים
1. **מפתח API של Anthropic** — נכנסים ל-console.anthropic.com → API Keys →
   Create Key, ומעתיקים את המפתח (מתחיל ב-`sk-ant-...`). שומרים אותו בצד.
2. אפליקציית **Shortcuts** (מותקנת כברירת מחדל באייפון).
3. את הטקסט של הפרומפט — נמצא בקובץ `engine/prompt_line.txt` שבפרויקט (תעתיק אותו
   בשלב 6 למטה).

---

## בניית הקיצור — שלב אחר שלב

פותחים **Shortcuts** → לוחצים **+** ליצירת קיצור חדש → נותנים לו שם
**"הוסף ריצה לטבלה"**. עכשיו מוסיפים את הפעולות לפי הסדר:

### 1. לקבל את צילומי המסך מה-Share Sheet
- למעלה בקיצור לוחצים על ה-(i) → מפעילים **Show in Share Sheet**.
- ב-**Accepted Types** משאירים רק **Images**.
- כך, כשמשתפים צילום מסך, הוא נכנס לקיצור כ-**Shortcut Input**.

### 2. השנה הנוכחית (2 ספרות)
- פעולה **Format Date**: כקלט בוחרים **Current Date**, פורמט מותאם אישית `yy`
  (שתי ספרות, למשל `26`).
- שם התוצאה יהיה `Formatted Date` — נשתמש בה בהמשך בתור **השנה**.

### 3. Base64 של התמונה/ות
- אם אתה משתף **צילום מסך אחד**: פעולה **Base64 Encode** על **Shortcut Input**
  → קרא לתוצאה `B1`.
- אם אתה משתף **שני צילומים יחד** (Summary + Map): הוסף
  **Base64 Encode** על הפריט הראשון → `B1`, ועוד **Base64 Encode** על הפריט
  השני → `B2`.
  (כדי לפצל לפריטים אפשר להשתמש ב-**Get Item from List** → Item at Index 1 / 2.)

### 4. בניית גוף הבקשה (Text אחד)
מוסיפים פעולת **Text** ומדביקים בדיוק את המבנה הבא. במקומות המסומנים גוררים
פנימה את המשתנים (Base64, והפרומפט מהשלב הבא):

```json
{
  "model": "claude-sonnet-5",
  "max_tokens": 400,
  "messages": [
    { "role": "user", "content": [
      { "type": "image", "source": { "type": "base64", "media_type": "image/png", "data": "‹גרור כאן את B1›" } },
      { "type": "image", "source": { "type": "base64", "media_type": "image/png", "data": "‹גרור כאן את B2›" } },
      { "type": "text", "text": "‹גרור כאן את משתנה הפרומפט מהשלב 5›" }
    ] }
  ]
}
```

> אם אתה משתף רק צילום אחד — מחק את בלוק ה-image השני (השורה של `B2`) יחד עם
> הפסיק שלפניו.

### 5. משתנה הפרומפט
- מוסיפים עוד פעולת **Text** ומדביקים לתוכה את כל התוכן של
  `engine/prompt_line.txt`.
- בשורה הראשונה שם כתוב `YEAR_HERE` — מוחקים את המילה הזו וגוררים במקומה את
  `Formatted Date` (השנה מהשלב 2).
- גוררים את ה-Text הזה לתוך שדה ה-`text` בשלב 4.

### 6. שליחה ל-Claude
פעולה **Get Contents of URL**:
- **URL**: `https://api.anthropic.com/v1/messages`
- **Method**: `POST`
- **Headers** (Add new field לכל אחד):
  - `x-api-key` → מפתח ה-API שלך (`sk-ant-...`)
  - `anthropic-version` → `2023-06-01`
  - `content-type` → `application/json`
- **Request Body**: בוחרים **File** ומכניסים את ה-**Text** מהשלב 4.
  (אם אין אפשרות File, בוחרים **JSON**? לא — כאן נבחר **File**/הטקסט כדי לשלוח כמו
  שהוא.)

### 7. שליפת שורת ה-CSV מהתשובה
Claude מחזיר JSON. מוסיפים:
- **Get Dictionary from Input** (על תוצאת השלב 6).
- **Get Dictionary Value** → Key: `content`.
- **Get Item from List** → Item at Index `1`.
- **Get Dictionary Value** → Key: `text`.
  התוצאה היא שורה אחת, למשל: `4.8.26,05:17-06:17,1:00:04,8.65,160,6:56,X,151,161,25`
  קרא לתוצאה הזו `NewLine`.

### 8. הוספה לקובץ Runs.csv ב-iCloud
Shortcuts לא "מוסיף" ישירות לקובץ, אז קוראים → מחברים → שומרים:
- **Get File** מ-iCloud Drive: נתיב `Shortcuts/Runs.csv`
  → סמן **Error if Not Found = OFF** (כדי שבפעם הראשונה לא ייכשל).
- **Text**: גרור את התוכן הישן, ירידת שורה, ואז `NewLine`.
  (אם רוצים כותרת בפעם הראשונה, אפשר להוסיף אותה ידנית פעם אחת לקובץ.)
- **Save File** ל-iCloud Drive, נתיב `Shortcuts/Runs.csv`,
  **Overwrite If Exists = ON**, **Ask Where to Save = OFF**.
- (רשות) **Show Notification**: "נוספה ריצה: NewLine".

זהו. שומרים את הקיצור.

## איך משתמשים בכל יום
1. פותחים את הריצה ב-Apple Fitness.
2. מצלמים מסך של ה-**Summary** (זמן/מרחק/הספק/קצב/דופק/קצב-צעדים), וגוללים
   מטה ומצלמים מסך של ה-**Map** (בשביל הטמפרטורה). אם הטיפוס (Elevation) מופיע
   במסך אחר — צלם גם אותו.
3. בוחרים את שני הצילומים ב-Photos → **Share** → **"הוסף ריצה לטבלה"**.
4. אחרי כמה שניות מקבלים התראה שהשורה נוספה.

## לקבל את קובץ ה-Excel "היפה" עם התבנית שלך
`Runs.csv` הוא הטבלה החיה. כדי לייצר ממנו את קובץ ה-xlsx המלא (עם העיצוב וגיליון
"תזונה") מריצים פעם ב-X את הממיר (על כל מחשב, או שאני מריץ לך):

```bash
python engine/csv_to_xlsx.py --csv Runs.csv --master template/fitness_master.xlsx --out fitness_master_updated.xlsx
```

## הערות
- **עלות**: כל שיתוף = קריאת API אחת עם תמונה. עלות של אגורות בודדות לקריאה.
- **פרטיות**: המפתח שמור בקיצור על הטלפון שלך בלבד; התמונה נשלחת ל-Anthropic
  לצורך החילוץ בלבד.
- **טיפוס (Elevation)** לא מופיע במסכי ה-Summary/Map — אם לא צירפת מסך שמראה
  אותו, הערך יהיה `X` (בדיוק כמו שכבר עשית בהרבה שורות בקובץ).
- **תיקון ידני**: תמיד אפשר לפתוח את הקובץ ולתקן/למחוק שורה. הקיצור לא נוגע
  בשורות קודמות.
