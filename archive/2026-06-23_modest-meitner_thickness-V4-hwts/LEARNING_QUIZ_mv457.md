## שכבה 1
1. `to_pixel(mm) = mm / resolution`; `to_mm(px) = px * resolution`. הקבוע הוא `Cfg_mv.resolution = 0.0650 mm/px`.
2. `(800 - 800) * 0.065 = 0`, `(600 - 600) * 0.065 = 0` → `(0.0, 0.0)`. הפיקסל שם **הוא** המרכז.
3. כדי לקבל מעלות במקום רדיאנים — ה-CSV וכל הספסיפיקציה במעלות.
4. `inspec(actual, reference, tolerance)`. דוגמה: `inspec(5.02, 5.0, 0.05)` → True; `inspec(5.07, 5.0, 0.05)` → False.
5. רק `find_surface_defects`. הסיבה: לדלג על אזורים שמיועדים לתעלות שמן או שוליים.
6. ראשית בודק `resolution` ב-`config457_mv.json`. אחר כך מריץ `Image_calibration` עם עצם ייחוס ידוע (100 mm).

## שכבה 2
1. `Spec` הוא מה שהשרטוט אומר. `workspec` הוא מה שהמצלמה אמורה לראות אחרי תיקון פרספקטיבה גלילית (`check_loc`).
2. כי בחור, "רחב מדי" לפעמים בסדר (חור נפתח), אבל "צר מדי" תמיד פסול (חור חסום). היחס המקל מסנן רק את הצד הקריטי.
3. תעלה תיחשב OK אם **לפחות צד אחד** (שמאל או ימין) של התעלה תקין. תכנון לעמידות חלקית.
4. כי יש רק `Body` אחד בעולם. שדות כיתה חוסכים instance ועוזרים לגישה גלובלית — אבל יוצרים סיכון אם פתאום ירצו לעבוד עם שני גופים.
5. 0=ריק/לא מזוהה; 1=ראש נכנס; 2=עצם שלם בפריים; 3=מגיע למרכז, דורש עצירה; 4=נעצר במקום, מוכן לצילום.
6. `Cfg_mv` הוא הגלובל שכל הקובץ משתמש בו (נוצר בשורה 1817). `Cfg` הוא משתנה ב-`init_system` שאף אחד לא קורא לו → דד-קוד.
7. (א) הוסף `self.Roundness = dimension()` ב-`Hole2_.__init__`. (ב) הוסף ל-`ok()` ו-`reject()` את `self.Roundness.ok()`. (ג) ב-`Detect_Holes`, חשב roundness אמיתי וכתוב ב-`h.Roundness.actual`. (ד) [אופציונלי] הוסף ל-`Data_processing`.

## שכבה 5
1. חיתוך שוליים → מסכה ירוקה → חישוב זווית הקו המרכזי של הגוף → סיבוב התמונה ליישור → חיתוך חוזר → חישוב גבולות הגוף → חיתוך סופי עם margin.
2. למצוא קו ישר דרך הנקודות שעל קצה הגוף — כדי לחשב את הזווית של הגוף ביחס לאופק.
3. כי `cut_image` רק מסובב — אבל הגוף הוא גליל, וההקרנה שלו על מישור עדיין מעוותת (קצוות "דחוסים", מרכז "מתוח"). `Image_alignment` משטיח את הגליל.

3. `refresh` קורא 2× פריים, `update_colors` בודק שתאורה ירוקה דולקת, `get_x` מנתח את התמונה.
4. `status` עולה מ-0 ל-1 (ראש נכנס) → 2 (עצם בפריים) → 3 (במרכז) → 4 (נעצר).
5. `loop1` עובר ל-`state=1`, כותב ל-PLC `[1,0,0,1,0]` (Green Off, White On).
6. `update_colors` מזהה תאורה לבנה → `WhiteOn=1`.
7. `loop1` עובר ל-`state=2`, כותב `[1,1,1,0,1]` (Green On, Conveyor On).
8. **thread חדש מופעל**: `t2 = Thread(target=run_prog).start()`.
9. ב-thread: `Cfg_mv.counter += 1`, `sttprog=1`, `Analize_Process()` מופעל:
   - `cut_image(img_W, img_G)` → שומר ב-`dev_img\\2.x.jpg`.
   - `Image_alignment(...)` → שומר ב-`dev_img\\3.x.jpg`.
   - bitwise + morphology + mask → `imgtoshow`.
   - `Detect_Holes` → שומר `dev_img\\4.1.jpg`.
   - `Detect_Lugs` → שומר `dev_img\\5.x.jpg`.
   - `Detect_Grooves` → שומר `dev_img\\6.x.jpg`.
   - `find_surface_defects` → שומר `dev_img\\7.x.jpg`.
10. `Data_processing(imgtoshow)` → מוסיף בלוק טקסט תחתון, OK/X גדול, חותמת. שומר `dev_img\\8.1.jpg`.
11. `sttprog = 2 if OK else 3`. שמירה: `results\\img_toShow {counter} .jpg`.
12. ב-`loop1`, `t2.is_alive()=False` → `state=0`, מוכן למחזור הבא.
