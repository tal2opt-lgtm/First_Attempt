# דף ה-web — מעקב ריצות

אפליקציית web של קובץ יחיד (צד-לקוח בלבד) שמעלים אליה צילום מסך של ריצה
מ-Apple Fitness, רואים את הנתונים שחולצו, מאשרים, והם נוספים לטבלה מצטברת.
מיועדת לרוץ מהאייפון (Add to Home Screen).

## קבצים
- `index.html` — המסך והעיצוב.
- `app.js` — הלוגיקה: העלאה, קריאה ל-Anthropic מהדפדפן, טבלה, ייצוא.
- `normalize.js` — נירמול הערכים (זהה ל-`engine/schema.py`), נבדק גם ב-Node.
- `test_normalize.js` — בדיקות נירמול (`node docs/test_normalize.js`).

## איך זה עובד
1. פותחים את הדף באייפון (דרך כתובת GitHub Pages) → **Add to Home Screen**.
2. בהגדרות (⚙️) מדביקים פעם אחת מפתח Anthropic API. הוא נשמר בדפדפן של המכשיר
   בלבד ונשלח רק ל-Anthropic.
3. **מעלים צילום/י מסך** (אפשר Summary + Map יחד) → **חלץ נתונים**.
4. בודקים/מתקנים את השדות → **הוסף לטבלה**.
5. הטבלה נשמרת מקומית (localStorage). אפשר לייצא **CSV** (תואם בול לתבנית) או
   **Excel**.

## הפעלת GitHub Pages
בהגדרות המאגר: **Settings → Pages → Build and deployment → Deploy from a
branch**, בוחרים את הענף ואת התיקייה **/docs**, ושומרים. הכתובת שתתקבל היא
הקישור לאפליקציה.

הטבלה מגיעה מאותחלת עם 14 הריצות הקיימות. הכל נשאר על המכשיר של המשתמש.
